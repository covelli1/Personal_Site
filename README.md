# Vincent Nguyen — Personal Portfolio

Personal portfolio site built with React, Vite, and Tailwind CSS. Hosted on Vercel.

## Stack

- React 18 + React Router
- Vite 8 (rolldown)
- Tailwind CSS v3
- FontAwesome (free-solid)

## Development

```bash
yarn install
yarn start      # dev server on port 3001
yarn build      # production build
```
